# Data Deletion Instructions for Space Invaders

**Last updated: March 2026**

## Overview

Space Invaders does not store any Facebook user data on external servers. All game data is stored locally on your device only.

## How to Delete Your Data

To delete all locally stored game data (scores and player names):

1. Navigate to the folder where Space Invaders is installed.
2. Delete the file named **`scores.db`**.

This will permanently remove all saved scores and player name history from your device.

## Facebook Data

No Facebook user data is retained after closing the game. Your Facebook display name is used only during the active game session and is not persisted to disk.

If you would like to revoke the application's access to your Facebook account:

1. Go to [Facebook Settings → Apps and Websites](https://www.facebook.com/settings?tab=applications).
2. Find **Space Invaders** and click **Remove**.
